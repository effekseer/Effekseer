
# Notarization

- Download a package from CI.

- Unzip and open dmg file.

- Make working directory and copy files from Script/Notarization_Mac

- Make Effekseer Directory in the working directory

- Copy files from dmg file.

- Call commands

```sh
sh Effekseer_notarytool_setup.sh "Apple ID" "TEAMID" "App-specific password" "effekseer-notarytool"
sh Effekseer_cert.sh "Developer ID Application: Your id (TEAMID)" "effekseer-notarytool"
```

Run separately for arm64 and x64. The script signs each Mach-O file with minimal
entitlements, audits all architectures, notarizes the app and DMG, validates the
stapled tickets, and checks Gatekeeper. Keep both notarization logs with the release.
See [the signing instructions](../../Script/Notarization_Mac/README.md) for required
files, entitlements, credentials, and validation details.

- Copy a dmg file which is generated by scripts to Effekseer release package

- Zip Effekseer release package
